SM service hosts and partition membership
Each SM service host represents one manager instance per independent plane/subnet; these controls affect all its instances together. The displayed master is the common elected host role. Individual per-plane elections are outside this model. 0x9234 = full membership in partition 0x1234; 0x1234 = limited membership. Two limited endpoints cannot communicate. This control represents SM administration, not a host assigning its own membership.

 
Diagnose, repair, validate
Inject an exercise, inspect a supported diagnostic while the fault exists, repair it, then run a new passing collective check. Repair alone never changes a failed result to passed.
Try one dependency at a time
  1. Lose one leaf uplink and inspect the remaining path. Lose both uplinks on one rack side and watch that rail become unavailable.
  2. Interrupt a shared spine, then its partner. Compare the rails affected within the same plane.
  3. Compare physical link state with logical reachability. A cable being up does not establish MTU, BGP or partition compatibility.
  4. Use the configuration workflow to repair the cause; inspect the counters and run a fresh check.
Individual faults
Rail selection above applies here. Switch faults use the switch selected in Configuration. Shared spines affect every rail assigned to that plane.

Monitor the consequences
Queue occupancy, errors, ECN/PFC events and credit wait are teaching counters, not predicted packets, bytes, latency or throughput. Hardware port rates identify a reference topology only. Queue gauges can fall; event counters remain cumulative.
