Use the [cluster simulator](/lab/cluster-simulator/) to practice provisioning, GPU rail troubleshooting, storage dependencies and job recovery. This is an independent educational model, not access to licensed BCM software or real GPU hardware.

## Start with five free minutes

Sign in with a verified Wirewalk Institute account. Creating an account does not require buying a course. Each account receives one five-minute trial, starting when a cluster is launched or resumed. Reading guides and choosing a configuration do not start the clock.

## Add an hour for $10 USD

One purchase adds 60 minutes of hosted lab access. The checkout charges $10 USD once. There is no recurring subscription, automatic renewal or automatic top-up. Unused purchased time carries over between sessions and has no scheduled expiry. All current hosted cluster configurations share the same account balance; future products may have separate pricing disclosed before purchase.

Stripe handles card payment. Credit appears only after payment is verified by the server. Returning from checkout or seeing a success URL alone does not grant time. If confirmation is delayed, choose “Check payment status” rather than paying again. You can leave and return; payment notifications can credit the account without an open browser. A card payment can be declined without affecting existing credit.

## Pause whenever you need to

Time is measured in active elapsed milliseconds on the server, independently of accelerated model ticks. “Pause” freezes the lab and stops usage. While paused, resume before stepping, issuing console commands or changing the model. Closing the tab, switching it to the background or losing the connection pauses access; disconnect detection can use up to four seconds. There is no charge beyond the available balance and no overage billing. One active session per account prevents concurrent tabs from sharing the same running session.

Progress is saved automatically. When time runs out, the model stops; it is not deleted. You can inspect the saved state, export it, and buy more time to resume. A downloaded session contains model state only, not purchased time or authentication. Imported state cannot add credit.

## Refunds and account help

For a duplicate purchase, an incorrect balance, an access problem or a refund request, contact [sales@wirewalk.com](mailto:sales@wirewalk.com) with the receipt reference. Do not email your password or card details. Refunds are handled individually; applicable customer rights are unaffected. Refunded credit is removed. If that time was already consumed, the account can show a negative credit balance that offsets future top-ups; this never charges a card automatically. Disputed payments suspend the corresponding credit pending review.

Accounts use the existing Wirewalk Institute sign-in, email confirmation and password recovery. The lab uses Cloudflare for account-session state and Stripe for payment. Read [privacy information](/privacy/) before entering data. Use synthetic examples, not credentials, customer inventories or sensitive research data.
