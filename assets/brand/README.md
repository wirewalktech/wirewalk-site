# Wirewalk logo family

Approved logo concepts generated with the built-in image tool and converted to flat, outlined SVG paths. SVGs contain no embedded images, font dependencies, or scripts. Original generated PNGs are retained alongside the derived assets.

- `wirewalk/`: main brand, terracotta #D97757.
- `wirewalk-ai/`: AI practice, terracotta #D97757.
- `wirewalk-studio/`: Studio practice, plum #775478.
- `wirewalk-forensics/`: Forensics practice, teal #276B70.

Each folder contains a standard SVG, a reversed SVG for dark backgrounds, PNG exports at 512/2048/4096 pixels wide, and a standalone mark as SVG and 32/180/512/2048 pixel PNGs. Transparent backgrounds are preserved. The standalone marks share the original parent-brand geometry; generated wordmark variants preserve their approved compositions.

Use SVG for the website and scalable reproduction. PNG sizes are rendered from vectors, rather than enlarged raster pixels. Use the reversed wordmark on dark backgrounds. Keep clear space and never stretch the proportions.

The main website uses `wirewalk/wirewalk.svg` in its shared header/footer and order pages. Brand variants are supplied as assets, ready for their own site integrations.
